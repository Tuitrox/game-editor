# Атлас механик

## Запуск и обновление

В каталоге с compose.yaml запустите `docker compose up -d --build` и откройте http://localhost:8787. На VPS редактор слушает loopback. Чтобы открыть его со своего компьютера, используйте SSH-туннель, например `ssh -L 8787:127.0.0.1:8787 msk`.

Для обновления из Git выполните `git pull --ff-only` в каталоге репозитория, затем `docker compose up -d --build`. Проекты хранятся в томе project_data.

Прямой запуск на Python 3.10+ — `python server.py`. В этом случае SQLite хранится в data рядом с сервером.

## Импорт примера

На экране «Проекты» нажмите «Импорт JSON» и выберите `examples/night-voyage.json`. Редактор проверит файл и создаст отдельный проект «Ночной рейс · Последний створ». Откройте вкладку «События» для просмотра всей схемы. Чтобы увидеть общий ярлык шквала с двумя стрелками, перейдите в «Грузовой теплоход», затем в «Генераторную».

## Схема событий

На текущем холсте у события или состояния одна карточка. Схема показывает связанные внешние объекты полупрозрачными ярлыками. На корневом холсте виден весь проект. Сплошная охристая стрелка связывает событие с его причиной, синяя обозначает установку состояния, зелёная пунктирная обозначает проверку условия. При отрицании стрелка становится красной. Пунктир по-прежнему означает проверку состояния, сплошная линия — причину события. Стрелка всегда направлена от входа к результату.

Нажмите на название карточки, чтобы проследить всю цепочку входящих связей в открытой схеме. Повторный щелчок или щелчок по фону снимает выделение. Кнопка ↗ открывает полное правило или холст состояния.

Точки на линиях задают повороты. Перетащите точку, чтобы передвинуть поворот, потяните за сегмент, чтобы поставить новую точку, или щёлкните по точке правой кнопкой, чтобы убрать её. Пересекающиеся линии независимы. Положение и размер карточек, а также ручные точки сохраняются для открытого пути. Когда меняется состав объектов, вложенность или логика правил, редактор заново расставляет карточки и прокладывает линии. Размеры карточек сохраняются.

## Холст

Кнопка «В текст» на любой вкладке открывает описание текущей ветки. В нём собраны иерархия, состояния, параметры и правила событий, включая прямые связи с другими ветками. Кнопка «Скопировать» переносит описание в буфер обмена. На уровне проекта в текст попадают также сущности пула без размещения.

Выберите проект или создайте новый, указав название и описание. Каждая сущность, включая корень, имеет собственное рабочее пространство.

На вкладках «Сущности», «Состояния» и «События» справа доступно общее дерево проекта. Треугольник раскрывает ветку, клик по названию открывает её на текущем холсте. Поиск оставляет совпадения и пути к ним. Выбранная ветка сохраняется при переключении между вкладками. Корень возвращает полный обзор, а кнопка «Дерево» показывает или скрывает панель.

В списке состояний рядом с владельцем указано количество его состояний. Нажмите на заголовок группы для раскрытия. При первом входе в раздел открыта группа самой выбранной сущности.

Плюс в строке сущности открывает под ней поля названия и описания. После создания новая сущность появляется в этой ветке. Плюс в заголовке пула открывает такую же форму внутри боковой панели. Escape закрывает черновик.

На холсте сущности нажмите «＋ Параметр», введите название и выберите тип «Число», «Строка» или «Да / нет». По умолчанию список пуст. Прежние числовые параметры отображаются как «Число».

В редакторе события внизу группы «Условия» нажмите «+ Параметр» и выберите нужный параметр. Кнопка «+ Состояние» рядом открывает выбор состояний. Для числа выберите знак сравнения и порог. Порог можно задать в процентах от текущего максимума (0–100) или выбрать «Константа», если число пока не определено. Например, условие «Температура > Константа» можно связать с последствием «Перегрет». Для строки укажите точный текст, для логического параметра — «Да» или «Нет». Локальному событию доступны параметры его сущности, в глобальном их можно выбрать по дереву размещений. Кнопка «Сменить параметр» меняет параметр в существующем условии. При смене на параметр того же типа сравнение и значение сохраняются. Проверки можно объединять через И, ИЛИ и НЕ. На схеме наведите курсор на стрелку от параметра, чтобы увидеть проверку.

Стрелка ← у заголовка возвращает к предыдущему виду, включая вкладку, прокрутку, раскрытые ветки и выделение на схеме. Для перехода к родителю нажмите его имя в пути над заголовком.

Чтобы связать изменения числовых параметров, в «Причинах» нажмите «+ Параметр», а в «Последствиях» — «＋ Изменение параметра». Выберите параметр в дереве и направление «Увеличилось» или «Уменьшилось». Например, у события «Нагрев двигателя» причиной может быть снижение уровня масла, а последствием — рост температуры. На схеме направление изменения подписано прямо на стрелке.

Ctrl+Z (на Mac ⌘Z) отменяет последнее сохранённое изменение текущего проекта. За одно открытие проекта доступны до 50 шагов. Обновление страницы и выход в список проектов очищают историю. При вводе текста работает обычная отмена набора.

- На вкладке «Сущности» клик по строке раскрывает или сворачивает её вложения. Кнопка ↗ открывает саму сущность. Сущность без вложений открывается кликом по строке. Счётчик состояний или событий ведёт сразу в соответствующую вкладку.
- Кнопка «＋ Вложенная сущность» создаёт сущность в текущем разделе и добавляет её в общий пул. Чтобы использовать существующую сущность, перетащите её из пула на нужную строку или выберите в пуле и нажмите «Вложить сюда». Для добавления в открытый раздел выберите «В текущий раздел» или перетащите сущность на фон. Один объект можно вкладывать в несколько разделов. Крестик убирает связь с выбранным родителем. Содержимое общей сущности видно во всех её размещениях.
- На вкладке «Состояния» состояния открытой ветки сгруппированы по владельцам. Щёлкните по строке, чтобы увидеть события, которые устанавливают это состояние или проверяют его в условиях. Щелчок по событию открывает правило. Плюс у владельца открывает форму создания состояния. Общий владелец показан один раз, а ссылки внутри строки открывают состояние в конкретном размещении.
- Кнопка добавления сверху создаёт объект открытой сущности. На вкладке «События» выберите дочернюю сущность в списке и нажмите «＋ Событие внутри», чтобы привязать новое правило к ней. Двойной щелчок по фону схемы событий создаёт событие.
- В условиях и причинах события поддерживаются вложенные И/ИЛИ и НЕ. В локальном событии проверяется состояние его источника. В разделе «Глобальные события» группу для «Все из» или «Любой из» выбирают на раскрытом дереве проекта. Поиск подсвечивает совпадения, сохраняя видимыми родительские ветки. Зажмите свободное место на карточке и перетащите её между блоками или в другую группу. Кнопка «НЕ» на карточке включает и снимает отрицание. В область НЕ помещается один блок, в том числе целая группа. Одна сущность в разных помещениях может участвовать дважды. Источник нового события по умолчанию привязан к текущему пути, для общего правила используйте «Глобальные события». Старые правила с общей сущностью действуют для всех её размещений. В последствиях указываются смены состояний и порождение событий. «Связи систем» показывает межсистемные зависимости.

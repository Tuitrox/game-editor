# Атлас механик

## Запуск и обновление

В каталоге с compose.yaml запустите `docker compose up -d --build` и откройте http://localhost:8787. На VPS редактор слушает loopback. Чтобы открыть его со своего компьютера, используйте SSH-туннель, например `ssh -L 8787:127.0.0.1:8787 msk`.

Для обновления предыдущей версии распакуйте архив поверх исходников, затем повторите команду сборки. Compose использует прежний том project_data. Если в базе есть проект старой версии, он появится в списке со всеми сущностями и правилами. Созданные в новой версии проекты пустые. Не используйте down -v при обновлении: этот ключ удаляет том с базой.

Прямой запуск на Python 3.10+ — `python server.py`. В этом случае SQLite хранится в data рядом с сервером.

## Импорт примера

На экране «Проекты» нажмите «Импорт JSON» и выберите `examples/night-voyage.json`. Редактор проверит файл и создаст отдельный проект «Ночной рейс · Последний створ». Откройте вкладку «События» для просмотра всей схемы. Чтобы увидеть общий ярлык шквала с двумя стрелками, перейдите в «Грузовой теплоход», затем в «Генераторную».

## Схема событий

На текущем холсте у события или состояния одна карточка. Схема показывает связанные внешние объекты полупрозрачными ярлыками. На корневом холсте виден весь проект. Сплошная охристая стрелка связывает событие с его причиной, синяя обозначает установку состояния, зелёная пунктирная обозначает проверку условия. Стрелка всегда направлена от входа к результату.

Нажмите на название карточки, чтобы проследить всю цепочку входящих связей в открытой схеме. Повторный щелчок или щелчок по фону снимает выделение. Кнопка ↗ открывает полное правило или холст состояния.

Точки на линиях задают повороты. Перетащите точку, чтобы передвинуть поворот, потяните за сегмент, чтобы поставить новую точку, или щёлкните по точке правой кнопкой, чтобы убрать её. Пересекающиеся линии независимы. Положение и размер карточек, а также ручные точки сохраняются для открытого пути. Когда меняется состав объектов, вложенность или логика правил, редактор заново расставляет карточки и прокладывает линии. Размеры карточек сохраняются.

## Холст

Выберите проект или создайте новый, указав название и описание. Каждая сущность, включая корень, имеет собственное рабочее пространство.

- Создайте сущность кнопкой ＋ в пуле. Перетащите её в нужное место или нажмите на имя в пуле, затем на холст. Карточку можно передвинуть. Кнопка «Открыть холст» ведёт внутрь. Название и описание редактируются по отдельности, Enter сохраняет поле, Shift+Enter переносит строку, а разделитель «Сущности» раскрывает список прямых вложений. Стрелка у элемента пула открывает его напрямую. Стрелка у заголовка возвращает к родителю по текущему пути, кнопка «Проекты» справа открывает список проектов.
- Одна сущность может находиться на нескольких холстах. Положение и размер задаются для каждого родителя отдельно. Перетяните ребро или угол карточки, чтобы изменить размер с шагом 5 пикселей. Крестик на карточке убирает её только с открытого холста.
- Переключатели «Сущности», «Состояния» и «События» закреплены над холстом. У каждого режима своя раскладка и размеры карточек. В двух последних режимах они показывают связанные объекты своей ветки. Состояние создаётся и редактируется на месте. Его холст показывает связанные правила, а событие открывается в отдельном окне.
- Кнопка добавления сверху создаёт объект открытой сущности. На вкладке «События» выберите дочернюю сущность в списке и нажмите «＋ Событие внутри», чтобы привязать новое правило к ней. Двойной щелчок по свободному месту добавляет объект текущей вкладки.
- В условиях и причинах события поддерживаются вложенные И/ИЛИ и НЕ. В локальном событии проверяется состояние его источника. В разделе «Глобальные события» группу для «Все из» или «Любой из» выбирают на раскрытом дереве проекта. Поиск подсвечивает совпадения, сохраняя видимыми родительские ветки. Перетаскивайте блоки за ручку между областями И, ИЛИ и НЕ. В область НЕ помещается один блок, в том числе целая группа. Одна сущность в разных помещениях может участвовать дважды. Источник нового события по умолчанию привязан к текущему пути, для общего правила используйте «Глобальные события». Старые правила с общей сущностью действуют для всех её размещений. В последствиях указываются смены состояний и порождение событий. «Связи систем» показывает межсистемные зависимости.

# Атлас механик

## Запуск и обновление

В каталоге с compose.yaml запустите `docker compose up -d --build` и откройте http://localhost:8787. На VPS редактор слушает loopback. Чтобы открыть его со своего компьютера, используйте SSH-туннель, например `ssh -L 8787:127.0.0.1:8787 msk`.

Для обновления предыдущей версии распакуйте архив поверх исходников, затем повторите команду сборки. Compose использует прежний том project_data. Если в базе есть проект старой версии, он появится в списке со всеми сущностями и правилами. Созданные в новой версии проекты пустые. Не используйте down -v при обновлении: этот ключ удаляет том с базой.

Прямой запуск на Python 3.10+ — `python server.py`. В этом случае SQLite хранится в data рядом с сервером.

## Холст

Выберите проект или создайте новый, указав название и описание. Каждая сущность, включая корень, имеет собственное рабочее пространство.

- Создайте сущность кнопкой ＋ в пуле. Перетащите её в нужное место или нажмите на имя в пуле, затем на холст. Карточку можно передвинуть. Кнопка «Открыть холст» ведёт внутрь. Название и описание редактируются прямо на карточке, а разделитель «Сущности» раскрывает список прямых вложений. Стрелка у элемента пула открывает его напрямую. Стрелка у заголовка возвращает к родителю по текущему пути, кнопка «Проекты» справа открывает список проектов.
- Одна сущность может находиться на нескольких холстах. Положение и размер задаются для каждого родителя отдельно. Перетяните нижний правый угол карточки, чтобы изменить размер с шагом 5 пикселей. Крестик на карточке убирает её только с открытого холста.
- Переключатели «Сущности», «Состояния» и «События» закреплены над холстом. Карточки дочерних сущностей сохраняют расположение. В двух последних режимах они показывают связанные объекты своей ветки. Состояние создаётся и редактируется на месте. Его холст показывает связанные правила, а событие открывается в отдельном окне.
- Кнопка добавления сверху создаёт объект открытой сущности, кнопка внутри дочерней карточки — объект этой дочерней сущности. Двойной щелчок по свободному месту ставит новое состояние или событие в выбранную точку. Собственные состояния и события можно перетаскивать.
- В условиях и причинах события поддерживаются вложенные И/ИЛИ и НЕ. В проверках «Все из» и «Любой из» сначала соберите группу размещений через дерево или поиск по пути, затем выберите состояние для группы. Одна сущность в разных помещениях может участвовать дважды. Источник нового события по умолчанию привязан к текущему пути, его можно изменить в окне события. Старые правила с общей сущностью действуют для всех её размещений. В последствиях указываются смены состояний и порождение событий. «Связи систем» показывает межсистемные зависимости.
